# Prompts for transfer pricing work

Prompts we use with AI assistants on transfer pricing tasks, published as plain markdown so they can be pasted, adapted or loaded into an agent's skills folder. Each prompt states its inputs, its rules and the output it expects, and is dated.

| Prompt | Use it when | Inputs |
|---|---|---|
| [Review a local file against a country profile](./review-local-file-against-country-profile.md) | A local file is drafted and needs checking against one country's rules before filing | Country profile from this repository, the local file, fiscal year |

Local files and benchmarks hold client data. Use these prompts only in a model whose data terms your firm has accepted, and strip what the task does not need.
