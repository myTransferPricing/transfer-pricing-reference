## Using these files

Each file has the same structure: front matter with the OECD profile date and source link, the OECD questionnaire sections as H2 headings, one H3 per question numbered as in the OECD profile, the answer, and the legal sources the jurisdiction cited. Drop the folder into a retrieval index or an agent's context as it is. A ready-made prompt that reviews a local file against one of these profiles is in [prompts](../prompts/README.md).
