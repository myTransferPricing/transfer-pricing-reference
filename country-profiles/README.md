# Transfer pricing rules by country

Country-by-country transfer pricing rules, one markdown file per jurisdiction, each summarised from that country's OECD Transfer Pricing Country Profile: arm's length principle, accepted transfer pricing methods, comparability analysis, intangibles, intra-group services, financial transactions, documentation thresholds and deadlines, dispute resolution (APAs and MAP), safe harbours and penalties.

The same profiles are browsable, with PDF download, at [mytransferpricing.com/country-profiles](https://mytransferpricing.com/country-profiles). More countries are added as the site publishes them.

## Using these files

Each file has the same structure: front matter with the OECD profile date and source link, the OECD questionnaire sections as H2 headings, one H3 per question numbered as in the OECD profile, the answer, and the legal sources the jurisdiction cited. Drop the folder into a retrieval index or an agent's context as it is.
